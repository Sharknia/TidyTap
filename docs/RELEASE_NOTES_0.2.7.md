# TidyTap 0.2.7

키보드·마우스를 다시 연결하거나 앱을 재시작했을 때 Caps Lock 설정 오류로 휠 반전까지 멈추던 문제를 수정했습니다.

- 장치 연결·해제와 절전 복귀 후 저장된 입력 설정을 자동으로 다시 적용합니다.
- TidyTap이 관리하던 Caps Lock 변환만 새 장치에서 누락된 경우 자동 복구합니다. 다른 Caps Lock 매핑과 장치별 사용자 지정 매핑은 덮어쓰지 않습니다.
- Caps Lock 조회·적용·복원에 오류가 나도 휠 반전·휠 단계·사이드 버튼·Finder·클립보드 단축키는 별도로 적용합니다.
- Caps Lock 오류와 요청 상태를 유지해 다음 장치 변경 때 다시 시도하며, 나머지 기능의 성공 응답이 Caps Lock 오류를 숨기지 않도록 했습니다.

## 확인한 범위

macOS 27.2에서 앱 테스트 180개와 입력 엔진 테스트 136개(선택 실행하는 실제 HID 읽기 검사 포함)가 통과했습니다. 격리 실행 검사는 설정 창, 앱·Helper 중복 실행 차단, 종료·재시작, 운영 설정 보존을 확인했습니다.

로컬 서명 설치본에서 외장 키보드의 TidyTap 변환이 빠진 상태를 재현한 뒤 시작 시 자동 복구를 확인했습니다. 별도 Caps Lock 충돌을 주입했을 때 다른 입력 기능이 적용되고 충돌 매핑이 보존되는 것도 확인했으며, 검증 후 원래 매핑과 전체 적용 상태를 복원했습니다. 실제 USB 분리·재연결, 물리 입력 전체, 구버전 macOS 실행은 이 검증에 포함하지 않았습니다.

버전은 0.2.7, 빌드는 15입니다. 공개 산출물과 업데이트 피드의 게시 여부는 실제 릴리즈 결과를 따릅니다.
