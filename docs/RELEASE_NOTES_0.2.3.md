# TidyTap 0.2.3 — 로컬 설치 후보

- 버전 0.2.3, 빌드 11. `codex/settings-scroll-image-filter` 브랜치의 로컬 설치용 빌드다.
- 설정 화면을 스크롤할 때 창 버튼과 앱 헤더가 겹치지 않도록 제목 표시줄과 콘텐츠 영역을 분리했다.
- 클립보드 히스토리에 `전체 / 이미지` 필터를 추가했다. macOS 26에서는 검색창과 조화되는 시스템 캡슐 형태를 사용하고 두 선택칸은 같은 폭으로 표시한다. 이미지 모드에서는 텍스트 검색을 비활성화하며, 전체로 돌아오면 검색어와 검색 초점을 복원한다.
- 필터 전환 중 오래된 검색 결과가 섞이거나 용량 초과 보호 때문에 선택하지 않은 항목이 자동 붙여넣기 대상으로 바뀌지 않도록 처리했다.

기능 코드의 앱 테스트 165개와 격리 실행 검사가 통과했고, Astra 적대적 리뷰에서 확정한 버그·회귀는 없다. 실제 한글 IME·VoiceOver·탄성 스크롤·외부 앱 삽입은 미검증 범위로 유지한다. [구현·검증 기록](SETTINGS_SCROLL_AND_CLIPBOARD_IMAGE_FILTER_PLAN.md)을 참고한다.

이번 요청은 로컬 설치다. 공개 태그·GitHub Release·Sparkle 업데이트 피드는 변경하지 않는다. 서명·공증 및 설치 결과는 아래와 같다.

## 상단바 입력 회귀 수정 — 빌드 10

최초 설치 후 사용자가 상단바 클릭·창 드래그 불가를 보고했다. 자동 GUI 도구로도 창 위치가 변하지 않았지만, 독립 검증 창에서도 같은 도구의 드래그가 실패했으므로 이 관찰만으로 코드 원인을 확정하지 않는다. 투명 창에서 `.fullSizeContentView`를 제거했던 변경을 되돌리고, 스크롤 뷰 상단을 루트의 안전 영역에 연결해 제목 표시줄의 배경과 입력 영역을 유지하면서 콘텐츠 겹침을 막는다. 창 배경은 투명 색 대신 AppKit 표준 `windowBackgroundColor`와 불투명 창으로 설정해 제목 표시줄에 빈 투명 입력 영역이 남지 않게 한다. 기존 설치본과 구분하기 위해 버전 0.2.3을 유지하고 빌드만 10으로 증가시켰다. 수정 빌드의 검증·재설치 결과는 아래에 기록한다.

## 필터 형태 마감 — 빌드 11

사용자 요청에 따라 0.2.3에 전체/이미지 필터의 형태 마감을 포함했다. 기존 `NSSegmentedControl`에 `segmentDistribution = .fillEqually`를 적용하고, macOS 26 이상에서는 `borderShape = .capsule`을 사용한다. macOS 26 미만에서는 기존 시스템 형태를 유지한다. 검색·선택·붙여넣기 및 기본 색상·포커스 동작은 변경하지 않는다. 로컬 설치본 구분을 위해 빌드를 11로 증가시켰다.
