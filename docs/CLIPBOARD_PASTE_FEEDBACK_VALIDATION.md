# 클립보드 붙여넣기 피드백 검증

작성일: 2026-09-30
상태: 구현 및 자동 검증 완료, 실제 사용자 입력 흐름 검증 진행 중

## 구현한 동작

- 붙여넣기 실행 시 기존 항목을 한 번만 최상단으로 이동한다. 대상 검사·헬퍼 응답이 실패해도 순위를 되돌리지 않는다.
- 키 미전송이 확인된 오류는 `붙여넣지 못했어요`, 결과 불명은 `붙여넣었는지 확인해 주세요`로 알린다. 알 수 없는 오류도 결과 불명으로 처리한다.
- 비활성·클릭 통과 패널 하나를 표시하고 마지막 안내 후 2.5초 뒤 닫는다. 알림에서 앱을 활성화하거나 키·마우스 입력을 받지 않는다.
- macOS 26 이상은 설정 화면과 같은 `NSGlassEffectView(.regular)`를 사용한다. 이전 OS는 Finder 피드백과 같은 `NSVisualEffectView(.popover)`를 사용한다. 기존 Finder 피드백은 변경하지 않는다.
- 실행 전에 목록 화면을 확보하고 그 화면의 상단 중앙에 표시한다. 다음 목록의 직전 시도 안내와 기존 단축키·삭제 버튼을 함께 유지한다.
- 시도 ID·단계·경과 시간·대상/전면 앱·AX 결과·쓰기/키 전송 결과·순위 변경 결과를 기존 로그에 추가한다. 추가 필드는 복사 본문·검색어·창 제목·AX 값을 수집하지 않는다.
- 격리 launch-smoke 실행은 클립보드 IPC를 설정 suite로 구분해 설치 앱·헬퍼와 섞이지 않게 한다. 일반 실행의 채널은 그대로다.

## 자동 검증

환경: Apple Silicon Mac, macOS 26.5.2, 현재 로컬 Xcode SDK. 테스트에 운영 기록을 사용하지 않았다.

| 검증 | 결과와 증거 |
| --- | --- |
| 앱 전체 XCTest | 169개 통과, 실패·건너뜀 0개. `build/feedback-tests-final.xcresult` |
| 입력 엔진 패키지 | 119개 통과. `/tmp/tidytap-feedback-engine-tests-final.log` |
| 실패/결과 불명 분류 | 키 미전송 오류·응답 시간 초과·미래의 알 수 없는 오류·권한 미허용을 구분하는 회귀 검사 통과 |
| 실제 AppKit 비활성 패널 | `canBecomeKey/Main=false`, 마우스 통과, key/main 창 및 전면 앱 유지, 현재 OS의 시스템 Glass 타입 검사 통과 |
| 반복 안내와 소멸 | 실제 타이머를 실행해 갱신 전 타이머가 새 안내를 닫지 않고, 마지막 안내 후 소멸하는 검사 통과 |
| 기존 안전 검사 | 포커스 복구·원래 요소 불일치·대상 전환·쓰기 전/후 commit gate의 기존 검사 포함 |

로그 경로와 `build`의 테스트 결과는 개발 환경의 증거이며 저장소에 포함하지 않는다. 순위 저장 함수의 기존 ID·내용·보관 계약은 입력 엔진의 회귀 검사 대상이다. 앱의 호출 시점은 소스 경로도 함께 대조했다.

## 실제 데스크톱 조사와 남은 범위

격리 suite에 합성 텍스트 두 건을 넣고 앱을 실행했다. 실제 전면 앱 정보로 호출한 내부 히스토리 요청에서 `clipboard-panel-visible=true entries=2`를 확인했다. 설치 앱과 격리 앱은 별도 IPC 채널 및 검증 복사본의 별도 앱 식별자로 구분했다.

자동화 도구 호출 사이 전면 앱이 바뀌고 히스토리 창이 key 상태를 잃었다. 설정 창 재열림과 도구의 창 선택도 관찰돼, 이 시도에서 실제 Enter 붙여넣기·재열기 순위·알림 외관을 검증했다고 판정하지 않는다. 이 문제를 해결하기 위해 안전한 대상 확인을 약화하지 않는다. 테스트 복사본은 설치 앱이 아니며, 결과를 운영 앱 수용 증거로 사용하지 않는다.

아직 확인할 항목:

- 실제 편집기·터미널에서 Enter·Shift+Enter·더블클릭 후 순위 이동, 실패 후 동일 항목 재시도, 실제 삽입 여부.
- 실제 입력과 클릭이 이어지는 동안 안내를 인지하는지, 작업 내용을 가리는지.
- 실제 헬퍼 응답 지연/유실과 늦은 응답이 새 시도를 덮지 않는 전체 경로.
- 실제 쓰기 후 포커스 이동 시 단계 로그, 키 미전송, UI 안내.
- 다중 모니터·전체 화면·화면 제거·macOS 15.1 fallback·macOS 27 시스템 조절.
- VoiceOver 실제 낭독과 Reduce Motion/투명도 설정에서의 외관.

키 전송 완료는 외부 앱의 실제 삽입 성공을 보장하지 않는다. 과거 오류의 사용자 클릭 여부도 소급 확정하지 않는다. 미검증 항목은 이후 실제 확인 결과로 갱신한다.
