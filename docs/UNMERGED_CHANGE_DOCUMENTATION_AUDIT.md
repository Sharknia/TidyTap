## 범위

- 기준: `origin/main`의 `3f1b068`부터 이 브랜치의 코드 기준 `c00e1a1`까지. `origin/main...c00e1a1`의 미병합 변경은 17개 커밋·66개 파일이다. 여기서 말하는 “검사”는 변경 코드·설정·스크립트와 **문서의 일치 여부**를 대조한 것이며 기능의 전체 수용 시험이나 독립 보안 감사가 아니다.

- 그 직전 0.1.4 릴리스 병합 PR #25(`f803a63`)은 신규 설치 토글·Helper 오류/수명 수정, README 두 언어, 개발·문제 해결 문서, 설정 스크린샷, 0.1.4 릴리스 노트를 포함한다. 이 병합은 이미 `main`에 있으므로 미병합 프리뷰 기능으로 다시 분류하지 않는다.

## 아직 완료 증거가 아닌 것

- 모든 클립보드 AC는 [수용 현황](CLIPBOARD_HISTORY_ACCEPTANCE_STATUS.md)에서 `부분`이다. 실제 대상 앱에서 서식·이미지 삽입, 실패 후 무입력, 한글 조합, 권한 거부·복구, macOS 15.1/27, 보조 기술을 완료로 판정하지 않았다.
- 원본 앱이 숨김·일시적·자동 생성 표식을 붙인 복사는 제외하지만, 표식 없는 비밀번호·민감 텍스트를 자동 판별한다는 보장은 없다. [사용자 안내](../README.ko.md)에 이 한계를 명시했다. 공개 전 개인정보 안내의 법적 적합성은 별도 검토 항목이다.
- macOS 27의 시스템 Liquid Glass 조절은 기본 AppKit 재질을 따르는 코드 경로만 확인했다. 실제 27에서 슬라이더 반응을 시험하지 않았다.
- `appcast.xml`은 이 브랜치에서만 존재하며 항목도 없다. 공개 `main`과 현재 브랜치는 모두 0.1.4/빌드 5다. 다음 공개 릴리스는 버전·빌드 번호를 올리고 서명·공증된 새 자산과 appcast를 준비해야 한다. Sparkle을 포함한 서명 프리뷰 설치와 자동 업데이트의 종단 간 성공은 별개다. 이번 문서 대조에서 DMG·앱을 다시 설치하거나 배포하지 않았다.
