# TidyTap 0.2.6

macOS 업데이트 후 키보드·마우스·Finder·클립보드 단축키가 함께 작동하지 않는 문제를 수정했습니다.

- macOS 27에서 사용하는 장치별 키 매핑 출력 형식을 지원합니다. 기존 출력 형식의 명령 경로는 유지합니다.
- 새 출력 형식에서는 키보드 장치만 대상으로 키 매핑을 확인하고 적용합니다.
- 키보드마다 매핑이 다르거나 읽기에 실패하면 기존 설정을 덮어쓰지 않고 중단합니다. 기존 Caps Lock 복구 기록도 보존합니다.

키보드 재연결로 장치별 매핑이 달라지면 설정 적용이 중단될 수 있습니다. 자동 재연결 복구는 이번 수정에 포함하지 않았습니다.

수정 근거와 검수·검증 범위는 [작업 계획서](HIDUTIL_MACOS27_COMPATIBILITY_PLAN.md)에 기록합니다. 구버전 macOS의 실제 실행과 물리 입력 검증은 확인한 범위만 기록합니다.
