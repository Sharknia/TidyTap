# 문제 해결

[README로 돌아가기](../README.ko.md)



- **마우스·Finder 기능이 반응하지 않을 때:** TidyTap의 손쉬운 사용 권한을 확인하고 앱으로 돌아와 하단 상태를 읽어보세요. 입력 모니터링은 별도로 필요하지 않습니다.
- **스크롤이 어색할 때:** 다른 마우스 앱의 겹치는 기능을 끄고, 휠 방향 반전과 단계 크기를 하나씩 켜서 확인하세요.
- **Caps Lock으로 한·영 전환이 안 될 때:** macOS에 두 입력 소스가 설정돼 있는지, 다른 도구가 Caps Lock을 바꾸고 있지 않은지 확인하세요. TidyTap은 입력 소스 목록을 관리하지 않습니다.
- **기능이 멈추거나 설정 적용에 실패했을 때:** TidyTap을 다시 열어 상태를 확인하세요. 보조 프로그램은 실패 후 자동 재시작하지 않습니다. 복원 문제가 남아 있다면 앱을 먼저 삭제하지 마세요.
- **클립보드 히스토리가 열리지 않을 때:** 기능 스위치가 켜져 있고 단축키를 저장했는지 확인하세요. TidyTap의 손쉬운 사용 권한을 확인하고, 다른 앱이 키를 먼저 처리한다면 다른 단축키로 바꾸세요. 설정의 `⌥V`는 추천일 뿐 자동 등록되지 않습니다. 클립보드 읽기 상태는 활성화할 때 별도로 확인합니다.
- **기록을 붙여넣지 못할 때:** 원래 입력칸으로 돌아가 다시 시도하세요. 대상 앱이나 입력 초점이 바뀌면 중단합니다. 같은 문제가 반복되면 오류 문구를 정확히 기록해주세요. 현재 성공 응답은 붙여넣기 키 이벤트 전송까지 확인하며 대상 앱의 실제 삽입까지 확인하지는 못합니다.
- **복사본이 열리지 않거나 업데이트가 없을 때:** 설치된 `/Applications/TidyTap.app`을 실행하세요. DMG나 다른 위치의 복사본 실행은 차단됩니다. 첫 수동 교체 전에는 구버전을 종료해야 합니다. 0.1.4 이하는 자체 업데이트가 불가능합니다. 0.2.0에서는 더 새 릴리스가 공개됐는지 확인한 뒤 **업데이트 확인**을 사용하세요.

해결되지 않으면 **[버그를 제보](https://github.com/Sharknia/TidyTap/issues/new)**해주세요. macOS·TidyTap 버전, 맥·마우스 모델, 켜둔 기능, 오류 문구나 재현 순서를 알려주시면 도움이 됩니다. 스크린샷에서는 개인정보를 제외해주세요. 이메일은 [zel@kakao.com](mailto:zel@kakao.com)입니다.


## 종료와 복원 상태 확인


1. TidyTap에서 **다섯 가지 입력 기능, 클립보드 히스토리, ‘로그인할 때 시작’을 모두 끕니다.** 휠 단계 크기도 꺼주세요. 저장 기록까지 지우려면 히스토리를 끄기 전에 **기록 전체 삭제**를 실행하세요.
2. **‘변경 사항이 적용되었습니다’**가 표시될 때까지 기다립니다. Caps Lock과 입력 소스 단축키가 TidyTap 사용 전처럼 동작하는지 확인하세요. 오류가 표시되면 앱을 지우기 전에 해결해야 합니다.
3. **활성 상태 보기**에서 `TidyTapHelper`를 검색해 종료됐는지 확인하고, TidyTap을 `⌘Q`로 종료합니다.
4. 삭제하려면 응용 프로그램 폴더의 **TidyTap.app**을 휴지통으로 옮깁니다. 앱 삭제만으로 `~/Library/Application Support/com.sharknia.TidyTap/clipboard-history`는 지워지지 않습니다. 제거 후 저장 기록도 삭제하려면 해당 디렉터리를 별도로 지우세요. 잠시 사용을 멈추는 경우 앱은 그대로 두면 됩니다.

TidyTap이 백업한 Caps Lock 설정을 복원합니다. 다른 입력 유틸리티가 변경한 설정까지 초기화하지는 않으며, 전용 제거 프로그램은 없습니다.


## 기기 호환성



확인 환경은 Apple M3 Pro MacBook Pro와 macOS 26.5.2입니다. 마우스 제조사에 따른 제한은 없지만 입력 전달 방식에 따라 호환성이 달라집니다. 모든 기기의 모든 기능을 검증한 것은 아닙니다.

0.1.3 릴리스에는 Finder 목록·아이콘·계층·갤러리 보기에서의 이동·복사 확인이 기록돼 있습니다. 휠 동작, Caps Lock 백업·복원, 권한 변경, 로그인·보조 프로그램 수명, 제거 순서의 전체 통합 검증은 별도입니다. [개발 및 검증 기록](DEVELOPMENT.ko.md)과 [릴리스 노트](https://github.com/Sharknia/TidyTap/releases/tag/v0.1.3)를 참고하세요.

[0.1.4 릴리스 노트](RELEASE_NOTES_0.1.4.md)는 앞선 신규 설치 토글 수정과 VM 확인을 기록합니다. 클립보드와 업데이트 변경은 [0.2.0 릴리스 노트](RELEASE_NOTES_0.2.0.md)에 있습니다.
