# 지적사항 처리 기록

주인님 요청 범위는 작업 계획 개정과 전체 금붕어 검토다. 제품 코드·계정·클라우드 자원은 수정하지 않았다.

| 통합 항목 | 원 지적 | 원 EGM / 사용자 등급 | 처리 | 독립 확인 |
| --- | --- | --- | --- | --- |
| A01 최종 schema·관리형 버전 호환성 | Z01, D01 | Major / 중간 | 개정 0.4에 Development 초기화·probe 분리·Production 승격과 구·신 버전 조합 수용 관문 명시 | 8단계 문서 누락 해소 확인 |
| A02 삭제 후 재생성 판정 | C01 | Major / 중간 | M04 재생성 시 실패, 실제 ACK 경계 미재현 시 미실행 명시 | 8단계 모호성 해소 확인 |
| A03 실행 수명 기준 | C02 | Major / 중간 | 창 닫기·⌘Q·로그인/업데이트의 수집·미러링 기준안 추가, 사용자 확정과 구분 | 8단계 기준 누락 해소 확인 |
| A04 한도 용어 | T01 | Nit / 낮음 | ‘공유 한도’를 ‘동기화 후 한도’로 통일 | 8단계 지적 위치 해소 확인 |

기준안의 문서화와 실제 시험 통과는 구분한다. 실제 OFF/ON·삭제 경합·계정·서명·두 Mac·용량 및 제품 모델은 아직 검증하지 않았다. 명시적으로 계획한 Gate0/Gate1 미완료를 새 제품 장애로 세지 않는다.

## 9단계 보완과 사용자 버전 지정

| 통합 항목 | 원 지적 | 원 EGM / 사용자 등급 | 개정 0.5 처리 | 독립 확인 |
| --- | --- | --- | --- | --- |
| A05 probe 실행 프로토콜 | I02 | Major / 중간 | Gate0-A 산출물에 사건별 사전 조건·순서·관찰 신호·중단 증거·기간·판정과 가명화 경로를 잠근 뒤 코드 작성 | 9단계 독립 재검토 완료 |
| A06 로컬 접근 권한 | R01 | Major / 중간 | 현행 0700/0600 수준을 라이브러리·계정·staging·백업·SQLite 부속/외부 binary·증거 파일까지 보존하고 생성/재실행/이관/백업 검사를 명시 | 9단계 독립 재검토 완료 |
| A07 문체 | U01~03 | Nit / 낮음 | 한도 용어 통일, 의도 평가 문구 제거, 미러링 중단 표시 조건 구체화 | 9단계 독립 재검토 완료 |

I01(Blocker / 해당없음)은 전체 제품 구현 준비에 한한 기존 선결 설계다. Gate1 완료 전 제품 구현을 허용하지 않는 계약을 유지했다.

후속 사용자 결정: 목표 **제품 버전 0.3.0**. 상위·UI·URS에 반영했다. 문서 개정 0.5와 제품 버전을 구분하며 실제 빌드 번호·프로젝트 설정은 변경하지 않았다.

W01(Nit / 낮음)은 마지막 재검토의 수명 용어 지적이다. 부모가 기존 수명 표와 일치하게 수정했으며 추가 독립 검토는 하지 않았다.
