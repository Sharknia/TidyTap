# 7단계: 기능 설계·구조·문체 검토

대상 개정 0.3, FeatureRange 1~59. 각 검토자는 새 대화 맥락에서 지정 persona와 기준, 대상 및 manifest의 local_context 2개·source_context 5개를 모두 읽었다고 보고했다. 파일 수정·제품 시험은 수행하지 않았다. 지정한 UI 맥락에는 과거 검토 상태에 대한 설명이 있으나 과거 보고서 자체는 공급하지 않았다.

## 구조 — managed07_structural, 완료

새 구조 지적 0건. 제목 계층·표·목록·링크가 유지되고 목표·범위·대안·위험·후속 관문이 연결돼 있다. OFF/ON 적합성, 제품 정책, 두 Mac 수용은 이미 명시된 관문이므로 해당없음으로 분류했다. 기술 실현 가능성의 통과 판정은 아니다.

## 문체 — managed07_style, 완료

### T01 — Nit / 낮음

위치: 23행의 ‘공유 한도’. 12행의 범위 제외인 공유 기능과 혼동될 수 있다. 47행에 맞춰 ‘동기화 후 한도’로 고친다. 한도 정책의 새 결정은 필요 없다.

OFF 완료·서버 수락 변경·조건부 관리형 채택·시스템 일정 제한 문구는 상태 판정과 후보 채택에 필요해 유지하는 것으로 판단했다.

## 설계 — managed07_design, 완료

### D01 — Major / 중간

위치: 14~16행, 보조 87~91·97·107·111행. 최종 모델의 CloudKit schema 개발 초기화·Production 배포와 관리형 모델 버전 간 호환성 관문이 빠져 있다. 기존 파일→v2 이관 경계만으로 관리형 구·신 버전이 같은 private DB를 쓰는 문제를 다루지 못한다. Apple model-limits의 Production type/field 변경 제약과 coredata-limits의 미배포 schema 동기화 실패 설명에 근거한다. 실제 장애는 미확인이다.

최소 개선: 채택 조건에 schema 배포·버전 호환성을 추가하고 Gate1에 지원 모델 버전/배포 순서, P4에 구·신 후보 조합 수용을 배정한다. Z01과 중복되는 schema 승격 부분은 통합 처리한다.

이미 Gate0/Gate1에 있는 ON/OFF·프로세스·계정·충돌·한도·이력 정책은 해당없음이며 새 결함으로 세지 않았다.
