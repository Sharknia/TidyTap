## What this proposes

주인님, 최근 기록과 보관함을 같은 창의 두 탭으로 나누고, 창을 열 때는 항상 최근 기록·전체 필터·빈 검색으로 시작하게 하는 계획입니다. 창 내부의 ⌘1/⌘2와 마우스로 전환하며, 같은 표시 세션에서는 탭별 검색·필터·선택·스크롤을 보존합니다. 고정과 일반 기록 삭제를 구분하고, 저장 성공·실패와 늦은 응답을 처리하도록 snapshot·콜백 계약과 검증 항목을 함께 정합니다. 실제 저장 연결은 상위 Gate1 계약이 준비된 뒤 진행합니다.

## How the existing system works, per this document

기존 패널에는 왼쪽 목록·오른쪽 미리보기, 검색과 전체/이미지 필터, 붙여넣기·취소·기록 삭제 동작이 있습니다. 패널 표시와 키 창 여부를 검사하는 키 처리 및 Enter 붙여넣기 상태 관리가 있으며, 이 동작들을 새 탭 구조에서도 유지합니다. 현재 ClipboardHistoryEntry에는 고정 상태와 일반 기록 소속이 없고, 패널은 항목 배열을 입력받습니다. 현재 SnapshotRenderer는 설정 화면을 그리므로 패널 합성 장면은 추가 작업에 해당합니다.
