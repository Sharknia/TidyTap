# UI 작업 계획 7단계 설계·구조·표현 검토

- 대상: 동기화 옵션 추가 요구 반영 후 1~83행, 나머지 178행까지 맥락 확인
- 검토자: ui07_design·ui07_structural·ui07_style, 모두 새 문맥에서 완료
- 결과: 신규 설계·구조 결함 없음. 낮음 등급 표현 2건을 완료 응답 후 보완했다.

## 설계 검토

ui07_design은 Feature Specification의 문제·범위·대안·위험 설명과 문서 자기일관성을 충족한다고 판단했다. 다음 항목은 해당없음으로 분류했으며 실제 구현 통과와 구분했다.

- 33·78·106~108·128행: 수집과 독립된 on/off, 취소/정리 상태·보존·재개·저장 실패·적용 세대가 실행 주체 계약에 연결된다.
- 80행: 자동 예약은 기준안이며 일정·요청 조정은 Gate0/1 미정이다. 초 단위 반영과 주기 선택 UI를 확정한 것으로 읽히지 않는다.
- 82행 및 상위 계획: 충돌 위험/사건 검토와 최종 규칙/실제 수렴 검증을 구분한다.
- 63~74행: 키 창·반복·조합 종료 거부·저장 성공 후 반영은 뒤 구현/시험과 연결된다.

## 구조 검토

ui07_structural은 신규 지적 없음으로 보고했다. H1/메타데이터/H2 목표·상태·입력/H3 동기화 구분이 순서대로 있으며 표·목록·링크·코드 블록이 유효하다. 대안·비목표·위험의 의미가 충족되므로 예시 제목과 다르다는 이유로 지적하지 않았다. Gate0/1 미완료는 기존 선결 작업으로 분류했다.

## T01 / Nit / 낮음: ‘진입 비용’의 비교 대상

- ui07_style, 37행. 기존 탭 시안과 진입 비용이라는 말만으로는 필요한 조작이 무엇인지 불분명하다.
- 반영: ‘보관함은 탭 전환 1회이며 창은 최근 기록으로 열고 ⌘2 또는 마우스로 전환’한다고 구체화했다.

## T02 / Nit / 낮음: ‘시간이 걸린다’의 범위

- ui07_style, 82행. 시간이 동기화 지연인지 개발/검토 기간인지 모호하며, 검토자는 첫 문장 DROP을 권했다.
- 반영: 사용자 질문의 판단에 필요한 이유를 남기되 동기화 지연으로 범위를 좁혔다. ‘서로의 변경을 받지 못한 채 같은 기록을 바꿀 수 있다’는 구체 원인으로 교체했다. 뒤의 충돌 사례·미확정/미검증 범위는 유지했다.
- 원시 등급은 바꾸지 않았고 표현 보완 뒤 별도 스타일 재검토는 하지 않았다. 전체 재검토에서 문서 의미를 다시 확인한다.

## 완료·읽기 증거

세 검토자는 해당 persona·지정 기준(Style 별도 기준 없음), UI 178행·상위 계획 244행·URS 313행·피드백 검증 87행·Apple 자료 4개를 전문 읽었다고 보고했다. Design은 패널의 키 상태/모니터/갱신/편집/숨김 코드를 대조했다. Structural은 구조·의미 위치를 확인했다. Style은 문구·원시 근거·후속 기록까지 대조했다.

제품 수정·생성·빌드·시험은 하지 않았다. 문서 보완은 검토 완료 후 주 에이전트가 적용했다. 실제 한글 조합·붙여넣기·충돌·CloudKit 연결·두 Mac 수렴은 미검증이다.
