- 작업: 채택 시안 계획 작성·추가 동기화 요구 반영·5단계 검토·문서 보완. 제품 코드와 실제 계정/클라우드는 변경하지 않았다.

## 결론

채택한 화면·키 동작과 동기화 옵션을 작업 계획에 연결했다. U0의 저장/실행 주체 계약 조사와 합성 UI fixture 설계는 가능하다. 전체 제품 구현은 상위 Gate0/1의 실제 연결·저장·충돌·적용 계약이 정해져야 한다.

금붕어 검토 중 발견한 지적은 문서에 반영했다. 그러나 마지막 구현 준비도 재검토에서 나온 중간 등급 1건과 낮음 2건을 보완한 뒤에는 독립 재검토를 추가로 실행하지 않았다. 특히 sync 의도의 독립 저장 경계는 추가 확인이 필요하다. 전체 무지적 통과·완전한 본구현 준비도 통과를 선언하지 않는다.

## 사용자 결정과 추가 질문 반영

| 항목 | 계획에 반영한 내용 | 상태 |
| --- | --- | --- |
| 화면 | 항상 최근 기록으로 열기, 같은 공간의 최근 기록/보관함 탭, 고정 목록이 최근 기록을 밀지 않음 | 사용자 채택 |
| 키·마우스 | 패널 내부 전용 ⌘1/⌘2, 마우스 전환 유지, 다른 앱의 키를 전역 등록으로 가로채지 않음 | 사용자 채택, 실제 환경 검증 전 |
| iCloud 옵션 | 설정에서 켜기/끄기, 로컬 수집과 분리, 수집 off에서도 스위치 접근, 끄기는 기록 삭제가 아님 | 옵션 제공은 추가 확정. 기기별/기본 off는 기준안 |
| 동기화 주기 | CKSyncEngine 자동 예약·원격 알림·재시도 기준안. 고정 N초 폴링이나 초 단위 반영 보장 없음 | 기준안. 구체 실행/요청 조정은 Gate0/1 |
| 충돌 | 다른 새 복사 기록은 병합 대상, 같은 ID의 고정/해제·삭제/옛 재전송·전체 삭제/오프라인 새 복사·만료/사용 갱신은 충돌 후보 | 위험·사건 검토 완료. 최종 승자/인과 경계·삭제 표식 보존/정리·실제 두 Mac 수렴은 미정/미검증 |

동기화 지연은 충돌을 없애지 않는다. 예를 들어 A에서 기록을 삭제한 뒤, 그 삭제를 받지 못한 B가 옛 상태를 재전송할 수 있다. 시간 간격이 있다는 이유로 삭제 부활 방지·메타데이터 병합 시험을 생략하지 않는다. Apple 문서도 자동 일정을 불확정으로 설명하고 앱별 충돌 처리를 앱 책임으로 둔다. [CKSyncEngine 근거](https://developer.apple.com/documentation/cloudkit/cksyncengine-5sie5)

## 작업 계획의 구체화

- 패널과 미리보기·검색·필터·붙여넣기를 재사용하고 탭별 메모리 상태만 추가한다.
- 첫 입력 검증 실패와 표시 중 갱신 실패를 구분하며 이전 계정/표시 세션을 재사용하지 않는다.
- 고정/해제/삭제는 현재 탭의 현재 선택을 우선하는 공통 갱신으로 연결한다. 과거 삭제 행을 다른 탭에 적용하는 경로는 없앤다.
- snapshot API 변경은 AppDelegate와 두 시험 파일의 호출자를 같은 U1 단계에 갱신한다.
- 한/영 패널 fixture는 언어 번들을 직접 주입하고 실제 기대 문자열을 확인한다.
- 마지막 보완은 sync 의도를 입력 Codable snapshot과 별도 preferences 키로 저장하고 전용 delegate/저장 경로로 적용하는 것이다. 기존 입력 설정 save의 Helper 실패와 혼동하지 않도록 UI-T17을 추가했다. 이 보완의 독립 검토는 미실행이다.

새 차단·높음으로 분류한 항목은 없다. 다만 마지막 중간 보완이 독립 검토됐다는 뜻은 아니다. 상위 Gate0/1 미완료는 원시 EGM 표준에서 Blocker/미통과로 판정됐지만 이미 계획된 선행 작업이므로 사용자 등급 해당없음으로 분리했다.

총 14명이 각각 fork_turns=none의 새 문맥으로 실행했다. 이해도는 대상만 읽었고 다른 단계에는 상위 계획·URS·피드백 검증·Apple 자료를 제공했다. 앞 단계 보고서는 8단계에만 추가했다. 사용자 추가 요구에 따라 문서를 개정하고 단계별 대상 사본·해시를 보존했다. 이전 대화·메모리나 답변을 리뷰어에게 공급하지 않았다. 호스트 지침 주입 제외와 자식 개별 도구 추적까지 독립 검증한 것은 아니다.

[처리 기록](goldfish_review_report.md)은 원시 지적 ID·등급·반영·확인 상태를 연결한다. [실행 기록](manifest.json)에 전체 완료 상태·사본/문맥/최종 해시·문서 검사를 기록한다. 본구현 미준비를 ‘미구현 파일이 없다’는 식의 새 결함으로 세지 않았으며, 마지막 보완도 검토 없이 통과 처리하지 않았다.

## 미실행 범위

제품 빌드·자동 시험·실제 키/한글 조합·붙여넣기·CloudKit 연결·실제 계정·두 Mac 수렴·서명/공증·배포는 실행하지 않았다. 문서 검사와 읽기 리뷰만으로 이를 대체하지 않는다. 아직 구현되지 않은 스위치나 자동 주기·충돌 처리 기능이 현재 앱에 있는 것처럼 안내하지 않는다.
