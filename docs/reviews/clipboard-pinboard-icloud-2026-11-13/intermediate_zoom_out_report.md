- EGM 등급: Major

- 근거: 기존 URS는 성공 응답을 기준으로 적지만 현행 `README.ko.md:24`는 성공 여부와 관계없이 붙여넣기 시도 시 갱신한다고 명시한다. `docs/CLIPBOARD_HISTORY_ACCEPTANCE_STATUS.md:5`도 요청 시 갱신을 최신 변경으로 기록한다. `Sources/App/AppDelegate.swift:450`은 대상 앱 검증 전에 갱신한다.

- 목표·재사용: 전체 히스토리와 1개 고정 보관함의 목표를 유지하고 기존 저장·검색·붙여넣기 경로를 확장한다. 불필요한 서버·계정 서비스·패키지나 세부 구현 추상화를 추가하지 않는다.
