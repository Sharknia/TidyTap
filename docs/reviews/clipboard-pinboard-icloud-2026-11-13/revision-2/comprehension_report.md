## What this proposes

주인님, 이 문서는 하나의 고정 보관함과 일반 클립보드 히스토리를 같은 Apple 계정의 Mac 사이에서 동기화하는 개발 계획입니다. 로컬 사용을 유지하면서 CloudKit 개인 데이터베이스를 연결하고, 고정 상태와 일반 기록 포함 여부를 독립적으로 관리하려고 합니다. 기능 범위는 사용자 확정이지만 보관·삭제·충돌 정책 일부는 제안이며, 0단계 기술 검증과 1단계 설계 산출물을 통과한 뒤 후속 제품 코드를 작성하도록 구분합니다. 구현·계정 설정·배포가 완료됐다는 문서는 아닙니다.

## How the existing system works, per this document

현재 저장소는 복사마다 UUID를 만들고 시각·본문을 파일로 저장하며, 앱과 Helper가 같은 디렉터리 잠금을 사용합니다. 일반 히스토리는 만료·중복·용량 조건에 따라 정리되고, 최근 사용 시각은 붙여넣기 성공이 아니라 시도 시작 때 갱신됩니다. 기존 목록·검색·필터·미리보기·서식 선택·붙여넣기 경로를 새 보관함에서도 재사용하려고 합니다. 현재 진단 로그에는 검색어와 선택 텍스트 미리보기가 남으므로, 새 저장소 이관과 별도로 비기록 전환과 기존 로그 정리를 계획합니다.
