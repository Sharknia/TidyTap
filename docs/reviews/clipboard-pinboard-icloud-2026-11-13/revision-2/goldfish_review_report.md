# 금붕어 지적사항 반영 기록

- 상태: resolved — 이전 리뷰의 문서 보완 7건 적용. 정책·스키마·실제 검증을 완료했다는 뜻은 아니다.
- 대상: `docs/CLIPBOARD_PINBOARD_ICLOUD_PLAN.md` 전체, 관련 URS 정렬 기준
- 승인 근거: 사용자의 ‘지적사항 반영해서 개발 계획서 보완하고, 다시 금붕어 리뷰 진행’ 요청. 이미 수정·재검토를 지시했으므로 같은 수정 승인을 다시 요청하지 않았다.
- 재검토 방식: 앞서 선택한 중간 정지 없는 전체 5단계 유지. 새 문맥 리뷰어 사용.

| 기존 ID·등급 | 분류 | 적용한 문서 보완 | 남은 단계 |
| --- | --- | --- | --- |
| G01 중간 | PROPOSE FIX | 고정 목록은 해제만 제공하는 기준안 A, 모든 목록 삭제를 별도로 두는 B의 결과·비용 명시. 유효한 일반 기록 유지와 이미 만료된 일반 기록 비복원, E03~04·AC-S04 연결 | 사용자 확정 범위와 구분한 정책 제안을 1단계에서 확정 |
| G02 중간 | PROPOSE FIX | 새 형식은 clipboard-library-v2로 격리. 기존 writer 종료 확인·백업/staging/완료 표시·실패 복구·구버전/재업그레이드 계약, E08 추가 | 원자성·계정별 경로·반입 ledger는 Gate1 설계 후 구현 |

| G04 중간 | PROPOSE FIX | 수정/생성 예정·단계별 정확한 제품·시험·스크립트 경로 제시. Gate0/Gate1 산출물·추가 파일 확정 전 코드 착수 금지 조건 명시 | 미확인 실행 주체의 entitlements/프로브 파일과 저장 세부 타입은 각 설계 산출물에서 확정 |
| G05 중간 | PROPOSE FIX | 사건표 E01~09와 명시적 최종 상태·미정 사건의 선행 결정 연결. 단계별 자동/실제 시험 경계와 필수 계정 시험, 미실행은 부분 판정, 관찰 가능한 지연 기록 정의 | E06 전체 삭제 인과 경계·동시 충돌·계정 표시 정책은 Gate1에서 기대값까지 확정 |
| G06 낮음 | PROPOSE FIX | 현행 시도 시작 기준을 계획과 URS 관련 정의·요구·흐름·DET·AC에 통일. 성공 응답 조건으로 되돌리지 않음 | 제품 코드 동작 변경 없음 |
| G07 낮음 | PROPOSE FIX | ‘몰래 삭제하지 않음’을 ‘상한 초과 시 기존 고정 항목 자동 삭제하지 않음’으로 변경 | 고정 한도 결정은 기존 Gate1 작업 |

이전 원시 D01/T01의 성공 응답 기준 복원 권고는 현재 코드·후속 기록과 맞지 않아 CONTEST다. 근거는 `Sources/App/AppDelegate.swift:450`, `README.ko.md:24`, `docs/CLIPBOARD_PASTE_FEEDBACK_VALIDATION.md`의 구현한 동작이다. 원시 등급을 덮어쓰지 않고 이전 개별 보고서에 보존했다. G06의 문서 정합성 보완은 적용했다.

계획된 Gate0/Gate1 결정은 새 결함 해결을 이유로 임의 확정하지 않았다. 재검토에서 문서 보완의 효과와 아직 본구현 준비도가 미완료라는 점을 각각 평가한다. 이번 요청은 제품 구현·클라우드 자원 생성·배포 지시가 아니다.

## 재검토 중 추가 반영

| 재검토 지적 | 원시 등급 / 사용자 등급 | 처리 | 확인 방식 |
| --- | --- | --- | --- |
| 6단계 C01 고정 전용 사용의 재등록 | Major / 중간 | 기준안에 같은 ID로 일반 기록 재등록·고정 유지 명시, E10 추가 | 새 문맥 이해도 재검토 1회에서 신규 지적 없음 |
| 7단계 T01 일반 포함을 켠다는 표현 | Nit / 낮음 | 특정 항목을 일반 히스토리에 포함한다는 문장으로 교체 | 8단계 전체 재검토의 반영 확인 |
| 9단계 K01 CloudKit 시험 격리 | Major / 중간 | 자동 시험 실제 연결 차단·실제 시험 계정/영역 검사·AC-S15/E11 및 LaunchSmoke/scheme 변경 범위 추가 | 새 코드/준비도 검토자 재검토 1회에서 신규 누락 없음 |
| 9단계 U01 중복 완료 경고 | Nit / 낮음 | 독자 결정에 도움이 없는 문장 삭제 | 새 스타일 검토자 1회에서 같은 문장 재지적 없음 |

문서 보완과 정책·CloudKit 실제 검증 완료는 구분한다. 이 기록은 원시 지적의 등급을 바꾸지 않으며 남은 선결 설계를 해결했다고 간주하지 않는다.

마지막 재검토의 낮음 U01(‘전송 대역’ 용어)도 ‘가짜 전송 계층’으로 통일했다. 이 마지막 용어 교체 뒤 추가 독립 재검토는 하지 않았으며, 단계별 재검토 상한을 넘겨 반복하지 않았다.
