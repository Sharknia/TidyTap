## D01: 최근 사용 갱신 기준과 기존 URS의 불일치

- 검토자: gf07_design / design_critic
- 원문 EGM 등급: Major
- 사용자 등급: 중간
- 대상: 44·49행
- 근거: 계획 44행은 실제 붙여넣기 요청으로 최근 시점을 갱신한다. 기존 URS의 URS-06·DET-07·DET-09는 붙여넣기 처리 성공 응답을 기준으로 삼고 실패는 순서를 바꾸지 않도록 적었다. 코드 `AppDelegate.swift:450`은 대상 앱 유효성 확인 전에 `promotePastedHistoryEntry`를 호출한다.
- 영향: 대상 앱 종료 등으로 실패한 요청이 일반 기록의 순서와 7일 보관 기점을 갱신하고, 이 변경이 다른 Mac에도 전파될 수 있다. 신규 동기화 기능에서 실제 발생은 미확인이다.
- 검토자 권고: 성공 응답을 기준으로 맞추거나, 요청 기준을 유지할 의도라면 요구 변경과 실패 시 보관 연장까지 명시한다.
- 해당없음: 고정 저장 한도·계정 전환 후 표시·CloudKit 실행 주체는 후속 단계에 이미 포함됐다.

## T01: ‘요청’과 ‘실제 사용’의 용어 혼용

- 검토자: gf07_style / style
- 원문 EGM 등급: Major
- 사용자 등급: 중간
- 대상: 44·49행
- 내용: 요청만 발생하거나 실패한 경우와 성공 응답을 받은 경우의 기준이 다르게 읽힌다. 기존 URS는 성공 응답을 기준으로 적고 있다. 현재 구현의 실제 오동작 여부는 미확인으로 보고했다.
- 검토자 권고: CALIBRATE. 성공 응답을 받으면 갱신한다는 표현으로 맞추고, 성공 응답도 대상 앱의 실제 삽입 확인은 아니라는 정의를 참조한다.
- 중복 관계: D01과 같은 정책 기준의 문서 정합성 문제. 독립 결함으로 이중 집계하지 않는다.
