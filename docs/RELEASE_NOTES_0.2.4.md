# TidyTap 0.2.4

- 버전 0.2.4, 빌드 12. Apple Silicon 및 macOS 15.1 이상을 대상으로 한다.
- 클립보드 히스토리의 최대 보관 개수를 100개에서 1,000개로 확대했다.
- 최대 7일·총 50 MiB·항목당 10 MiB 제한을 유지한다. 용량 제한을 먼저 넘으면 오래된 기록부터 정리한다.
- 설정의 보관 안내와 한국어·영어 문서를 새 정책에 맞췄다.

새로운 저장 형식이나 추가 설정 없이 기존 기록을 계속 사용한다. 이전 제한으로 이미 정리된 기록은 복구하지 않는다. 화면 상대 크기 대응은 이번 릴리스에 포함하지 않는다.

## 검증 범위

앱 테스트에서 실제 공통 정책으로 1,001개 합성 기록 중 최신 1,000개 보관, 새 복사 후 오래된 기록 정리, 1,000개 목록 검색을 확인한다. 총용량·보관 기간·중복 정리 등의 기존 입력 엔진 검증도 유지한다. 측정은 합성 텍스트 기준이며 이미지가 대부분인 최대 용량 상황과 실제 외부 앱 붙여넣기 전체 흐름까지 통과한 것으로 간주하지 않는다.
