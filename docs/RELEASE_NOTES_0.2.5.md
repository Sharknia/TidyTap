# TidyTap 0.2.5

붙여넣기가 중단돼도 작업 중인 앱의 입력을 이어갈 수 있도록 안내를 바꿨습니다.

- 붙여넣기 오류창을 클릭과 키보드 입력을 받지 않는 짧은 안내로 교체했습니다.
- 붙여넣기를 중단한 경우와 응답이 없어 입력 여부를 확인할 수 없는 경우를 구분합니다.
- 히스토리에서 붙여넣기를 시도한 항목은 성공 여부와 관계없이 맨 위로 이동합니다.
- 목록을 다시 열면 직전 붙여넣기 시도 안내를 확인할 수 있습니다.
- 대상 앱과 포커스 확인, 클립보드 쓰기, 키 전송 단계의 로컬 진단 로그를 보강했습니다.

알림은 macOS 26 이상에서 시스템 Liquid Glass를 사용하고, 이전 지원 OS에서는 기존 시스템 재질을 사용합니다. 자동 재붙여넣기는 하지 않습니다.

검증한 범위와 남은 실제 사용 확인은 [검증 기록](CLIPBOARD_PASTE_FEEDBACK_VALIDATION.md)에 구분합니다.
